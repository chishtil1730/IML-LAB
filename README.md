## 🛠️ How to Use

Clone the repository:

```bash
git clone https://github.com/chishtil1730/IML-LAB.git
```

Navigate into a directory and run the Python scripts:

```bash
cd IML-LAB/ML_Experiments
python your_script.py
```

💡 Tip: Use a virtual environment to manage dependencies.
